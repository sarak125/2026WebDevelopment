Web Technologies

HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure content on the web.
It acts as the foundational skeleton of a webpage, telling web browsers how to display text, headings, images, and other multimedia.

  1. Heading
  2. Paragraphs
  3. Lists
  4. Images
  5. Colors

CSS

CSS stands for Cascading Style Sheets. It is a standard rule-based stylesheet language used to control the visual presentation, layout,
and formatting of documents written in markup languages like HTML. It is one of the core foundational technologies of the World Wide Web.

  • Comments
  • Colors
  • Backgrounds
  • Borders
  • Margins

JavaScript

Javascript is a lightweight, high-level, and multi-paradigm programming language. It is used to create interactive content on web browsers.
However, it has evolved into a powerful general-purpose language that is used across many environments.

  • Syntax
  • Operators
  • If Conditions
  • Loops
  • Strings

Bootstrap

Bootstrap is a free, open-source front-end framework used to build mobile-first websites and web applications.
It has HTML, CSS, and JavaScript-based design templates for typography, forms, buttons, navigation, and other interface components.
It uses a flexible container and column layout to scale across phones, tablets, and desktops automatically.
